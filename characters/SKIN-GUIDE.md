# スキン（キャラクター）作成ガイド

> **かんたんな方法**: アプリ内の「🎨 キャラ変更」→「＋キャラクターを新しく作る」を使うと、
> AI画像生成と連携してこのガイドの内容を自動でやってくれます。以下は手動で作りたい人向けです。

デスクトップペットの見た目は「スキン」として自由に追加できます。
**1スキン = 1フォルダ**で、画像（PNG）と定義ファイル（character.json）を置くだけです。プログラムの知識は不要です。

## スキンの置き場所

| 環境 | フォルダ |
|---|---|
| インストール版で自分用に追加 | `%APPDATA%\desktop-pet\characters\`（トレイ →「設定フォルダを開く」の中の `characters`） |
| 開発版・全員に配布したいスキン | プロジェクトの `characters\` |

同じフォルダ名のスキンが両方にある場合は、ユーザー側（%APPDATA%）が優先されます。
フォルダ名が `_` で始まるもの（`_template` など）は一覧に表示されません。

## いちばん簡単な作り方

1. `characters\_template` フォルダをコピーして、好きな名前に変える（例: `mycat`）※`_`で始めない
2. `idle_0.png` を自分の画像に差し替える（透過PNG推奨）
3. `character.json` の `name`（表示名）と `frameWidth` / `frameHeight`（画像のピクセルサイズ）を画像に合わせて書き換える
4. アプリを再起動 → パネルの「🔄 キャラ変更」またはトレイの「キャラクター」に登場します

## character.json の仕様

```json
{
  "name": "コーギー",          ← 必須: メニューに表示される名前
  "frameWidth": 32,            ← 必須: 画像1枚の幅(px)
  "frameHeight": 22,           ← 必須: 画像1枚の高さ(px)
  "scale": 4,                  ← 任意: 表示倍率(既定4)。ドット絵はぼやけず拡大されます
  "facing": "right",           ← 任意: 素材の向きのメモ(動作には影響しません)
  "theme": { "accent": "#e8974e" },  ← 任意: ボタン・吹き出し枠の色
  "animations": {
    "idle":  { "frames": ["idle_0.png", "idle_1.png"], "fps": 2 },   ← 必須(1枚以上)
    "walk":  { "frames": ["walk_0.png", ...], "fps": 7 },            ← 任意
    "work":  { "frames": ["work_0.png", ...], "fps": 4 },            ← 任意
    "sleep": { "frames": ["sleep_0.png", ...], "fps": 1 }            ← 任意
  }
}
```

### アニメーションと挙動の関係（重要）

挙動（移動・クリック・ドラッグ・計測など）はアプリ本体が持っていて、スキンは**画像を差し替えるだけ**です。
アニメの有無で自動的に振る舞いが変わります:

| アニメ | いつ使われるか | 省略した場合 |
|---|---|---|
| `idle` | 待機中 | 省略不可（これだけは必須） |
| `walk` | ときどき左右に散歩（左向きは自動で反転表示） | **散歩しなくなる**（座りキャラ向け） |
| `work` | 作業計測中 | idle で代用 |
| `sleep` | 10分無操作 | idle で代用（💤は出ます） |

- `frames` は同じ画像を並べてもOK（例: `["a.png","a.png","b.png"]` で「たまに瞬き」を表現）
- クリックやドラッグの当たり判定は**画像の表示範囲そのもの**です。極端に小さい画像はクリックしづらくなるので、`scale` で調整してください
- ツールチップや吹き出しの表示位置はサイズから自動計算されます

## ドット絵をコードで生成したい場合（上級）

`tools\generate-corgi.js` / `generate-boy.js` が参考になります。ピクセル配列から PNG を生成し、
輪郭の自動暗色化（edgeDarken）で統一感を出しています。`npm run sprites` で再生成できます。

## うまく表示されないとき

- `character.json` が壊れている・必須項目が足りないスキンは、**無視されて一覧に出ません**（アプリは正常起動します）。起動ログに「スキンを無視」と出ます
- 画像ファイル名の大文字小文字・拡張子（.png）を確認してください
